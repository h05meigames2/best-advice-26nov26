> My grandmother, peeling garlic at the kitchen table the night I failed my exams, said, 'A burnt pot still feeds the family—start the next one.'

An entry for the [make.fun bounty "The Best Advice I Ever Got"](https://make.fun/competitions/u-pangg7-the-best-advice-i-ever-got-358cefb0): one sentence, at most 200 characters, about the best advice the writer ever received.

## How it works

`main.py` is a deterministic Python 3 program using only the standard library — no network, no randomness. It writes the single sentence (143 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), creating the output directory if needed. A built-in check asserts the sentence stays within 200 characters and remains exactly one sentence.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
